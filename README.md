# Licorera Pininos

App de administración para la licorera: ventas al detal y por caja, compras al proveedor, inventario, movimientos y ganancias.

Se instala desde el navegador (Chrome o Edge) en el computador y en el celular, y funciona sin internet.

Usuarios de prueba: Administrador `1234`, Vendedor 1 `1111`, Vendedor 2 `2222`.
